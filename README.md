# Flowseal presets for Forkop

Неофициальный переключатель **22 пресетов** для OpenWrt / Forkop **1.0.5**.
Каждый пресет занимает две фиксированные секции: YouTube и Discord.
Проект экспериментальный: **alpha**, не универсальное решение для любого оператора.

Исходные стратегии взяты из [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube),
автор zapret — [bol-van](https://github.com/bol-van/zapret).
Основа маршрутизации — [Forkop](https://github.com/ushan0v/forkop).
Проект не является официальным продуктом этих авторов.

## Установка

Сначала сохраните резервную копию OpenWrt. Команда выполняется **по SSH на роутере от root**,
а не в PowerShell на компьютере. Нужны рабочие DNS/HTTPS и доступ к GitHub и пакетным feeds OpenWrt.

Для релиза `v0.1.0-alpha.2`:

```sh
wget -O /tmp/flowseal-install.run https://github.com/malinnary/forkop-flowseal-presets/releases/download/v0.1.0-alpha.2/forkop-flowseal-install.run && sh /tmp/flowseal-install.run
```

Или скачайте `.run` из [Releases](https://github.com/malinnary/forkop-flowseal-presets/releases),
проверьте приложенный SHA-256, скопируйте файл в `/tmp` и запустите `sh /tmp/flowseal-install.run`.
Не отключайте проверку TLS при ошибке загрузки: проверьте время роутера и CA-сертификаты.

Установщик:

1. Проверяет OpenWrt, root, блокировку параллельных операций и целостность пакета.
2. Если Forkop отсутствует — устанавливает официальные пакеты **1.0.5** с закреплёнными SHA-256.
3. Добавляет отсутствующие зависимости; sing-box и zapret устанавливает через менеджер Forkop.
4. Устанавливает CLI и страницу LuCI **Службы → Flowseal Presets**.
5. При новой установке/обновлении файлов проверяет все пресеты на установленных компонентах.

Пресет автоматически **не применяется**. Откройте страницу переключателя, выберите вариант,
нажмите **Проверить**, затем **Применить**. Начать можно с `general-alt11`, но эффективность
нужно проверять именно в вашей сети. Автозапуск Forkop включается отдельно после проверки связи.

## Совместимость и ограничения

- Проверенная среда: Cudy TR3000 v1, OpenWrt 25.12.2, Forkop 1.0.5, nfqws 72.20260307-r1.
- Поддержаны ветки установки apk/opkg. Чистая установка пакетов пока проверена **только mock-тестами**.
  На реальном TR3000 проверены обновление существующей установки и повторный запуск.
- Другие версии Forkop отклоняются без обновления или downgrade. Поддержка 2.x ещё не проверена.
- Для новой установки требуется минимум 40 MiB свободной flash; это запас-порог, не гарантия размера.
- Версии компонентов и зависимостей из feeds не закреплены, в отличие от пакетов Forkop.
- Установка не сбрасывает существующие правила. **Применение** пока допускает только чистые секции
  Forkop либо секции, созданные переключателем. VPN/подписки автоматически не объединяются.
- Обновление сохраняет копии файлов в `/root/flowseal-install-backup-*`. Повторный запуск
  с теми же файлами ничего не меняет. Другие активные payload/ruleset молча не перезаписываются.
- При ошибке копирования/валидации файлы переключателя откатываются. Уже установленные зависимости
  автоматически не удаляются: пакетная установка не является единой транзакцией.
- Если откат должен остановить Forkop, но DNS вручную направлен на `127.0.0.42`, он отказывается
  от изменений до безопасной перенастройки DNS.

## Что именно адаптировано

Это целевой перенос для YouTube/Discord, **не полная копия маршрутизации Flowseal**.
Выбор доменов/портов вынесен в sing-box/Forkop; внутренние `--hostlist`/`--ipset` исключены.
Общие игровые фильтры, широкие списки других сайтов и IP-set fallback не включены.
UDP-порты голоса направляются в секцию Discord, распознавание Discord/STUN остаётся в nfqws.
Параметры fake-пакетов, repeats и fooling автоматически не «оптимизируются».

Все 22 пресета прошли синтаксические проверки на тестовом роутере. Это **не доказывает**
качество видео/голоса или эффективность обхода. Подключение за другим роутером с VPN/zapret
может скрывать проблемы. История проверок: [TESTING.md](TESTING.md).

## CLI и удаление

```sh
flowseal-presets list
flowseal-presets status
flowseal-presets check general-alt11
flowseal-presets apply general-alt11
flowseal-presets restore
```

Для удаления распакуйте `.tar.gz` из релиза и выполните `sh uninstall.sh`.
Удаление сначала восстанавливает сохранённую конфигурацию и переносит собственные файлы
в резервную папку. Если настройки изменены вручную или откат угрожает DNS, операция прекращается.
Полный цикл удаления на чистом роутере ещё не проверен.

## Сборка

Python 3.10+, Git; shell-тесты требуют POSIX shell. Запускайте из корня репозитория:

```sh
git clone https://github.com/Flowseal/zapret-discord-youtube.git .upstream
git -C .upstream checkout --detach "$(python -c 'import json; print(json.load(open("upstream.lock.json"))["commit"])')"
python tools/import_upstream.py .upstream dist/inventory
python tools/compile_two.py
python tools/build_release.py
python -m unittest discover -s tests -v
sh tests/test_dependencies.sh files/dependencies.sh
```

Импорт требует чистого checkout и новых выходных папок. BAT-файлы никогда не запускаются;
в архив не включаются Windows EXE/DLL/SYS. Архив собирается по явному перечню файлов,
без пользовательских подписок, конфигураций и резервных копий.
Старые `compile_forkop.py`/`export_candidates.py` сохранены для аудита, не используются в релизе.
GitHub Actions собирает и тестирует пакет, а при теге `v*` публикует prerelease.
